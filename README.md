# Eya Luxury Boutique

One-page watch boutique website (English, French, Arabic) with GSAP ScrollTrigger, Lenis and Three.js.

## Run it on your computer
1. Open this folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click `index.html` and choose "Open with Live Server".

Do not just double-click index.html: the 3D gallery needs a local server to load the photos.

## Change things
- Prices, names and photos of the watches: the `W` list in `index.html`.
- WhatsApp number: the `WA` constant in `index.html`.
- Photos: replace the files in `images/` and keep the same names.
